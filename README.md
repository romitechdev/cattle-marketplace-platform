# Cattle Marketplace Platform

A premium marketplace platform for buying and selling cows, featuring product listings and a built-in FAQ section.

## Features

- Browse and view cattle listings
- Buy and sell cows through the marketplace
- Frequently asked questions (FAQ) section
- Responsive design built with vanilla JavaScript

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Project Structure

- `index.html` — main page
- `main.js` — core application logic
- `sapi.js` — cattle listing functionality
- `faq.js` — FAQ section logic
- `style.css` — site styles

## Getting Started

Open `index.html` in a browser.
